# Ticket Booking System API

Веб-приложение и REST API для системы бронирования билетов на мероприятия.

## Стек технологий
* **Backend:** Node.js, Express.js
* **Database:** MySQL (`mysql2/promise`)
* **Security:** JWT (`jsonwebtoken`), `bcrypt`
* **Environment:** `dotenv`
